# 用户画像分析页面 - 技术架构文档

## 1. 系统架构

### 1.1 整体架构
```
┌─────────────────────────────────────┐
│         Streamlit Web App           │
├─────────────────────────────────────┤
│  UI Layer (页面布局与组件)           │
├─────────────────────────────────────┤
│  Visualization Layer (Seaborn 图表)  │
├─────────────────────────────────────┤
│  Data Layer (Mock 数据生成)          │
└─────────────────────────────────────┘
```

### 1.2 技术栈
- **Python**: 3.8+
- **Streamlit**: Web 应用框架
- **Seaborn**: 统计图表可视化
- **Matplotlib**: 底层图表渲染
- **Pandas**: 数据处理和分析
- **NumPy**: 数值计算

## 3. 页面布局设计

### 3.1 布局结构
```
┌──────────────────────────────────────┐
│           Header (标题)               │
├──────────────────────────────────────┤
│  ┌─────────────┐  ┌──────────────┐   │
│  │  性别分布图  │  │   年龄分布图  │   │
│  │             │  │              │   │
│  └─────────────┘  └──────────────┘   │
├──────────────────────────────────────┤
│        Data Summary (数据摘要)        │
└──────────────────────────────────────┘
```

### 3.2 配色方案
- **主色调**: 深蓝色系 (#2C3E50)
- **强调色**: 珊瑚色 (#FF6B6B), 青绿色 (#4ECDC4)
- **背景色**: 浅灰色 (#F8F9FA)
- **图表配色**: Seaborn 调色板

## 4. 数据流设计

### 4.1 数据流程图
```
Mock 数据生成 → 数据处理 → 统计分析 → 图表渲染 → 页面展示
```

### 4.2 数据结构
```python
# 用户数据 DataFrame
columns: ['user_id', 'gender', 'age', 'age_group']

# 性别统计
columns: ['gender', 'count', 'percentage']

# 年龄分组统计
columns: ['age_group', 'gender', 'count', 'percentage']
```

## 5. 图表设计规范

### 5.1 性别分布图
- **图表类型**: 水平条形图
- **颜色**: 渐变蓝色系
- **标签**: 显示数量和百分比
- **尺寸**: 800x400px

### 5.2 年龄分布图
- **图表类型**: 分组条形图
- **颜色**: 按性别区分
- **标签**: 显示数量和百分比
- **尺寸**: 800x400px

## 6. 性能优化

### 6.1 缓存策略
- 使用 `@st.cache_data` 缓存 mock 数据
- 使用 `@st.cache_resource` 缓存图表对象

### 6.2 渲染优化
- 预计算统计数据
- 避免重复计算
- 优化图表渲染参数
