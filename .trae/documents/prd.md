# 用户画像分析页面 - 产品需求文档 (PRD)

## 1. 项目概述

### 1.1 项目背景
开发一个基于 Streamlit 和 Seaborn 的用户画像分析页面，用于可视化展示用户性别与年龄分布数据，帮助业务团队快速了解用户群体特征。

### 1.2 项目目标
- 创建交互式的数据可视化页面
- 展示用户性别分布的分组条形图
- 展示用户年龄分布的分组条形图
- 使用 mock 数据进行演示

## 2. 功能需求

### 2.1 核心功能
1. **性别分布可视化**
   - 分组条形图展示不同性别的用户数量
   - 显示百分比标签
   - 支持悬停显示详细数据

2. **年龄分布可视化**
   - 按年龄段分组的条形图（如：18-24, 25-34, 35-44, 45-54, 55+）
   - 支持按性别分组对比
   - 显示各年龄段的用户数量和占比

3. **数据筛选功能**
   - 可选的数据筛选器（如：时间范围、用户类型等）
   - 动态更新图表数据

### 2.2 页面布局
- 顶部：页面标题和简介
- 中部：主要可视化图表区域
  - 左侧：性别分布图
  - 右侧：年龄分布图
- 底部：数据摘要和统计信息

## 3. 技术需求

### 3.1 技术栈
- **前端框架**: Streamlit
- **可视化库**: Seaborn + Matplotlib
- **数据处理**: Pandas
- **数据类型**: Mock 数据

### 3.2 性能要求
- 页面加载时间 < 3 秒
- 图表渲染流畅
- 响应式布局

### 3.3 设计要求
- 简洁专业的 UI 设计
- 清晰的图表标签和图例
- 协调的配色方案
- 良好的可读性

## 4. 数据规范

### 4.1 Mock 数据结构
```python
# 用户数据结构
{
    'user_id': int,
    'gender': str,  # '男', '女', '其他'
    'age': int,
```

### 4.2 数据规模
- 总用户数：1000-5000 条 mock 数据
- 性别分布：相对均衡
- 年龄分布：符合正态分布
